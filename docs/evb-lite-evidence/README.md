# EVB Lite evidence

Put the raw evidence from the hardware discovery session here, and reference
it from §3 of `../evb-lite-integration.md`:

* DevTools HAR exports of the device portal / Device Hub traffic
* Probe responses saved by the app (`docker compose cp app:/data/discovery ./docs/evb-lite-evidence/`)
* Example JSON / CSV sample payloads
* Screenshots of the portal (firmware version, settings pages)
* Excerpts or page references from EVident documentation

Do not store Wi-Fi passwords or other secrets here.
